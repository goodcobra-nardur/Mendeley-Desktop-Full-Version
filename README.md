## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **PDF Management** — Effortlessly read, annotate, and organize your PDF files for efficient research.
- **Bibliographical Database** — Create and maintain a comprehensive database of all your research documents.
- **Collaboration Tools** — Share your database with colleagues and collaborate on projects seamlessly.
- **Automatic Bibliographies** — Generate citations in various styles for use in Word or OpenOffice.
- **Multi-format Support** — Manage documents in XML, RIS, BIB, and more, enhancing flexibility in project management.

### Advanced Features:
- **Document Tagging** — Easily filter and search documents by author, keywords, or tags for quick access.
- **Batch Editing** — Streamline your workflow with the ability to edit multiple entries at once.
- **Web Integration** — Use the Mendeley Bookmarklet to add documents directly from popular academic sites.
